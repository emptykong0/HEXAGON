# Pixel ice effects
Source: https://github.com/patch-gg/pixelfx
Effects: ice/ice-lance and ice/snowflake-burst; exported with tools/render.mjs --sheet, 30 fps.
License: MIT, see PIXELFX-LICENSE.txt. Ice lance also credits the MIT energy bolt recipe, Copyright (c) 2026 Hugo Duprez (https://www.spritefusion.com/pixel-art-vfx/energy).
Godot uses the exported atlas metadata; nearest filtering. Snowflake burst is accelerated to 0.85 seconds for impact recovery. No stock actor is included.
